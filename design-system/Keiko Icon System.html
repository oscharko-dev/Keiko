01 — GRAMMAR

The rule

Six sentences. Follow them and you draw a Keiko icon automatically — whoever you are, whenever it is.

Grid
A 24 × 24 unit field. Everything visible lives in the 20-unit clear area (2-unit margin).
Stroke
1.6 units, constant. Round caps, round joins. No fills.
Colour
Always currentColor — monochrome (grey-white). Green/red only on interaction.
The lift
One closed contour = one seam of ≈ 2 units (≈ 34° on a ring), at the natural pen-start point.
Open glyphs
Gestures such as +, ✓, send carry no forced seam — they belong through stroke quality.
Corner radius
2–2.5 units on framed shapes.
02 — CONSTRUCTION

The drawing template

How every new icon is made — three steps, always the same.

1

Build on the grid

Construct the geometry closed on the 24-unit grid, inside the 20-unit clear area. Still ordinary.

2

Lift one pen

Open exactly one seam of ≈ 2 units — at the pen-start (top / “12 o’clock”). Never two.

3

Round caps, monochrome

Stroke 1.6, round caps, currentColor. No fill, no colour. Done — and it belongs to the family.

04 — LIBRARY

The library

One monochrome hand across the whole product: workspace, the digital twin, model types, voice, governance and data. Names match the keys in lift-glyphs.js / Icons.tsx, so they’re 1:1 swappable in code.

05 — GUARDRAILS

Do & don’t

Do

One seam per contour, at the top pen-start.

Round caps, constant 1.6 stroke.

Monochrome — currentColor, colour only on interaction.

Don’t

No two (or more) seams — the lift loses its calm.

No flat/sharp caps and no closed frames without a seam.

No permanent green and no filled areas.

06 — IMPLEMENTATION

How it lands in code

The same Ico wrapper as today — only the paths carry the seam. Every glyph above is copyable, currentColor SVG. 

// Keiko · Lift — drop-in for packages/keiko-ui/.../Icons.tsx
// Only addition vs. today's Ico base: the seam in closed
// contours. Stroke / caps / viewBox stay exactly the same.

function Ico({ size = 24, sw = 1.6, children }) {
  return (
    <svg width={size} height={size} viewBox="0 0 24 24"
      fill="none" stroke="currentColor" strokeWidth={sw}
      strokeLinecap="round" strokeLinejoin="round" aria-hidden="true">
      {children}
    </svg>
  );
}

// search — the ONE open spot at 12 o'clock is the lift
export const search = (
  <Ico>
    <path d="M12.25 4.76 A6 6 0 1 1 8.75 4.76" />  {/* ring, open at top */}
    <path d="M14.7 14.7 L20 20" />                 {/* handle */}
  </Ico>
);
