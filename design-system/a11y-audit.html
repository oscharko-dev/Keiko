Foundations · Proof

Contrast, measured live.

Not a single ratio on this page is typed by hand. Each one is computed in your browser right now — the token is rasterised to sRGB and run through the WCAG relative-luminance formula, in all four resolved palettes at once: dark, light, dark + high-contrast, light + high-contrast. The worst of the four decides the verdict.

00 — RESULT

Verdict

Computed on load across every component tone. A pass means the worst of the four modes still clears its WCAG minimum (4.5:1 for text, 3:1 for large text, UI borders and the focus ring).

Engine self-test
Before trusting the table, the measurement engine is validated against known pairs. These must read exactly as physics dictates, or every number below is suspect.

Method
Translucent surfaces (status tints, the accent-dim tag) are composited over their base surface before measuring, exactly as the eye sees them. Large-text / UI rows require 3:1; everything else 4.5:1. AAA marks tones that also clear the stricter 7:1 / 4.5:1 bar.
