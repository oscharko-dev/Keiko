Editor chrome & tabs

The frame around the code well — the parts a developer reads a hundred times an hour without noticing. Tabs, breadcrumbs, splits, minimap and the status bar. We orient at the strong ideas in JetBrains IDEs and rebuild them in the Keiko hand: one monochrome surface, one green accent reserved for state, every value from --ed-*.

02 — TABS

Tab states

A tab carries identity (file-type badge + name) and state (active, dirty, pinned, preview, diagnostic). State never rides on colour alone — the active marker is a shape (top rule), dirty is a dot, pinned is a glyph.

03 — SPLITS

Editor groups

Side-by-side editors share one tab grammar. The focused group is signalled by a one-pixel accent edge — never a heavy fill — so attention is clear without the layout shouting.

04 — BREADCRUMBS

Structural navigation

The breadcrumb traces the file path and the symbol path down to the cursor. Each crumb is a jump target; the trailing crumb names the enclosing symbol, so you always know where the caret lives.

Clicking a crumb opens a sibling switcher — jump to any peer file or symbol without leaving the keyboard. The dropdown reuses the context-menu grammar (see Navigation).

05 — STATUS BAR

The status line, mapped

Quiet by default, dense with truth. Diagnostics on the left (counts, branch), document facts on the right (position, indent, encoding, EOL, language). Each item is a click target that opens its own control.

06 — MINIMAP

Minimap & overview ruler

A 56 px reduction of the file: syntax-tinted line blocks, a draggable viewport slider, and right-edge marks for diagnostics and search hits. Decorative density, never a control surface.

12345678
// reducerexport function reduce(s, a) { switch (a.type) { case "add": return [...s, a.item]; default: return s;}}
Slider
The viewport rectangle uses --ed-minimap-slider — a 10% neutral wash, visible on the tinted blocks but never competing with them.
Marks
Right-edge marks reuse status hues: error, warning, and accent for the current find match — the same overview ruler signals Monaco draws.
Opt-in
The minimap is dense by nature. It ships off by default in compact density and on wide editors only — decoration must earn its width.
