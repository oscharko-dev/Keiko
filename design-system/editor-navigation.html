Navigation & search

Moving through a codebase is the most-repeated action in the editor, so it gets the most-refined surfaces: one omni-search, fast file and symbol jumps, find & replace, completion, quick docs, and the right-click menus that tie it together. Every overlay shares one grammar — a field, a result list, a keyboard footer.

One overlay (double-⇧) that reaches everything — files, symbols, actions, settings. Scopes are tabs; results are typed and previewable; the keyboard footer always shows the next move.

07 — PRINCIPLE

One overlay grammar

Field → list → footerEvery search surface is a query field, a typed result list with group labels, and a keyboard footer. Search Everywhere, Go to File and Find in Files are one component, three scopes.
Match = accent, not boldMatched characters take --accent-text. We never bold matches — bold reads as a second weight and fights the mono grid.
AI lives inlineCompletions, refactors and actions from Keiko appear inside the existing list/menu with a green badge — never a separate popup that competes for the same keystroke.
Keys are always shownResult footers and menu rows surface the shortcut, so the mouse path teaches the keyboard path.
