Foundations

The raw material: a warm-neutral oklch palette (hue 160), one type pairing, a 2-based spacing rhythm, three radii, two elevations and the dot-grid surface. Every value is a CSS variable in keiko-tokens.css — change it once, it changes everywhere.

01 — COLOUR

Palette

One hue (160, a warm green-grey) carries the whole neutral system in oklch, so dark and light are the same palette at different lightness. The orca green #4EBA87 is the only chromatic accent.

Note
Never colour alone. Status is always paired with an icon, label or shape — and in light theme the chromatic tokens darken (e.g. --accent-text → oklch(0.48 0.13 160)) so green/red/amber text clears 4.5:1 on white. --fg-dim (0.66) and --fg-faint (0.64) sit deliberately close: both are WCAG-checked and kept monotonic, not a duplication.

03 — SPACING

Spacing & rhythm

A 2-based scale. Tight steps (2–8) handle dense UI — icon gaps, control padding; larger steps (12–32) separate cards and sections. Lay rows out with gap, not margins.

2pxhairline insets
4pxicon-to-icon gaps in a control cluster
6pxchip / small button padding
8pxdefault gap between related elements
10–12pxlist-row padding, menu items
14pxcard inner padding, composer
18pxgap between cards
24pxdot-grid pitch · block spacing
32–48pxsection separation
04 — RADIUS

Corner radius

Three tokens plus a pill. Nested corners stay concentric — an inner radius equals the outer minus its padding.

--radius-sm9px · chips, inputs, menu items
--radius14px · cards, windows, panels
--radius-lg18px · the composer box
full999px · pills, status badges, toggles
05 — ELEVATION

Elevation

Two shadows do all the lifting. Both pair a soft drop with a 1px inner highlight so raised surfaces read as physical, not blurred.

--shadow-card
--shadow-pop
focus / valid · accent ring
Use
--shadow-card for resting cards and windows; --shadow-pop for the top-most / focused window, menus and popovers. The accent ring marks focus and valid connection targets — never a colour change alone.
06 — SURFACE

The workspace surface

Cards float on a framed, near-black canvas over a 24px dot grid (and an optional Liquid-Chrome wallpaper). The frame is a single hairline; the grid gives depth without lines.
