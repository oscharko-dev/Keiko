Git window

The surface where a developer reviews working changes, stages files, writes a commit, and opens pull requests — plus a commit History view and a Connect repository empty state. It keeps the information architecture of GitHub Desktop but renders entirely in the Keiko hand: monochrome warm-neutral surfaces, the orca-green accent reserved for selection and AI, the Lift icon set, and the editor diff palette. Ships in production as the cards/git-client window.

01 — SHOWCASE

The window, in three states

Changes and History share the window head, toolbar and two-column shell; only the left column and the right-pane header swap. Empty replaces the body with one centred Connect panel and mutes the toolbar.

02 — ANATOMY

Anatomy & tokens

Every value resolves from a design token — match by token name, never by re-typing a resolved colour.

TOOLBAR

Stacked cells — Repository · Current branch · Pull origin — split by --line-soft hairlines, on --surface. Right actions are bordered --card buttons.

STATUS SQUARES

Letter + tint, never colour alone: M --info, A --ok, D --danger, R --warn.

AI & SELECTION

Orca-green is reserved for selection (the --accent bar + --accent-dim row) and for Keiko's voice — the suggested summary's accent edge and the Explain-diff card.

DIFF

The right pane uses the editor background --ed-bg and the editor diff/syntax palette — --ed-diff-* rows and --ed-syn-* tokens.
