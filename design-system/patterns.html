02 — CONNECTIONS

Card connections

Windows link like a workflow graph. Ports appear on hover; click-to-connect draws an accent edge. While data flows, the edge animates — a flowing dash plus particles, denser for heavier exchange. State is shown by motion and a tag, never colour alone.
