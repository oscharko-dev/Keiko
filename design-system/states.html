A component isn't done until its states are. Keiko standardises eleven — from rest to conflict — defines which apply to what, and proves every applicable state across the seven canonical appearance modes. Toggle appearance & contrast in the sidebar; this page is the proof.

Rule
Ship a component only when every checked cell is implemented and screenshotted in the seven canonical modes. Loading uses the skeleton tokens; error uses --feedback-danger; syncing uses --feedback-info; conflict uses --feedback-warning — always paired with an icon and a word.
