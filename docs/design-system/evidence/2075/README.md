# Issue 2075 — hosted maintainer queue evidence

The browser suite serves the compiled production `serveMaintainerUi` handler and its package assets.
It replaces only same-origin maintainer API responses with deterministic non-customer fixtures.

Run:

```sh
npx playwright test --config tests/e2e/config/playwright.issue-2075-maintainer-review.config.ts --project=chromium
```

The 21 tracked captures cover dark/light desktop, dark/light high contrast, forced colors, reduced
motion, German mobile empty/unauthenticated, 403, 409 Conflict, 429, 503, audit, private security,
active/expired legal holds, loading, filtered-empty, native validation, 404 stale detail, and actual
submitting/busy rendering. The detail fixture contains HTML/link/image/script-shaped text and
the browser asserts that no executable/link/image nodes or external requests exist.

Every capture has a WCAG 2.2 axe result in `a11y-proof.json` (zero violations across all 21).
Production CSP remains active; axe is installed before navigation through the Playwright context,
and application CSP violation events are asserted empty before each scan. `fidelity-proof.json` is
regenerated by the same command and records hashes/identity byte sizes for all seven served assets.
The test writes result-less drafts; the custom reporter promotes them to `result: PASS` only after a
successful Playwright `onEnd`. A failed run deletes drafts and any prior PASS receipts, covered by a
negative reporter regression.

Handler tests pin listener separation, HSTS, content types, exact CSP, no inline assets, callback
routing, and cached `br`/`gzip` negotiation for GET/HEAD. Responses remain `no-store`; static
compression is computed once per asset and reused, with duplicate/oversized encodings falling back
to identity.

The screenshots contain only deterministic synthetic payload text. `a11y-proof.json` records the
real-browser axe result. No production/customer data is used.
