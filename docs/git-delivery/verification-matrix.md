# Governed Git Delivery Verification Matrix

Issue #479 closes the proof gap for Epic #470 by mapping each governed Git delivery outcome to concrete
implementation paths, regression tests, browser evidence, and operator evidence. The matrix is a
closure artifact, not a substitute for CI. It deliberately distinguishes executable tests from
non-gating browser coordinator evidence.

## Blocked, rejected, degraded, and recovery paths

| Scenario class                   | Representative trigger                                                                                          | Proof                                                                                                                      | Operator interpretation                                                                                                  |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Policy blocked                   | Protected/shared push target, disallowed PR base, no applicable policy rule.                                    | `git-delivery-policy.test.ts`, `pushRoutes.test.ts`, `prRoutes.test.ts`, browser manifests #476 and #477.                  | Policy pack denied the action. Change target or policy; do not retry unchanged.                                          |
| Preflight blocked                | Detached head, no staged changes, non-fast-forward branch, missing upstream, merge/readiness blocker.           | `git-mutation-preflight.test.ts`, `git-publish-gateway.test.ts`, `git-merge-gateway.test.ts`.                              | User-fixable repository state or provider readiness issue. Fix the named blocker before retrying.                        |
| Approval-held                    | Approval-gated policy without a valid, unexpired approval. The machine outcome is `approval-required`.          | `git-mutation-orchestrator.test.ts`, `actionSheetRoutes.test.ts`, `mergeRoutes.test.ts`, `GovernedMergeCard.test.tsx`.     | Request or refresh approval; no mutation has executed.                                                                   |
| Provider rejected                | Push non-fast-forward, PR permission/validation failure, merge head-modified, rate limit, provider unavailable. | `git-publish-node.integration.test.ts`, `git-pr-gateway.test.ts`, `git-merge-gateway.test.ts`, `git-merge-node.test.ts`.   | Provider returned a terminal failure after governed gates; use the typed reason and recovery disposition.                |
| Degraded prerequisites           | Unknown workspace, unavailable worktree, missing provider tooling or credentials, or no applicable policy rule. | `commitRoutes.test.ts`, `pushRoutes.test.ts`, `prRoutes.test.ts`, `mergeRoutes.test.ts`, UI API-failure tests.             | Fix the named prerequisite or configure policy/provider credentials; no deployment enable flag is involved.              |
| Evidence persistence best-effort | Ledger append failure after terminal outcome.                                                                   | `mutationEvidenceLedger.test.ts`, `commitRoutes.test.ts`, `pushRoutes.test.ts`, `prRoutes.test.ts`, `mergeRoutes.test.ts`. | Response still returns the governed outcome; support should investigate evidence storage before relying on audit export. |
| recovery-required                | Conflict or rewrite-adjacent failure requiring a governed recovery strategy.                                    | `git-mutation-evidence.test.ts`, `git-mutation-taxonomy.test.ts`, `git-mutation-orchestrator.test.ts`.                     | Use the suggested governed recovery action; do not use raw terminal reset/merge shortcuts.                               |

## Browser evidence boundary

Browser evidence for #475-#478 drives the real packaged CLI UI and real window registry while intercepting
governed BFF routes with deterministic governed JSON. That proves UI wiring, no-bypass affordances, and
browser-visible blocked/success states. It is not live GitHub/provider proof. Provider and execution proof
comes from the unit, integration, and server route suites listed above.
