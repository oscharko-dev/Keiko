# Epic #2095 M7 editor conformance matrix

This matrix is the Issue #2326 integration and traceability artifact for Epic #2095. It maps the M7
personalized/resilient editor substrate to named automated proofs and records the supported behavior
that must not be overstated during final closeout (#2327).

M7 intentionally reuses the existing editor, settings, watcher, agent, hot-exit, model-retention,
and governed AI-assist paths. It does not add an integration-only store, route, fake provider, or
security bypass.

## Platform compatibility and limitations

The automated M7 proofs are hermetic and intended to run on macOS, Linux, and Windows because they
avoid real provider calls, fixed ports, and host language binaries. Linux remains authoritative for
editor release and performance evidence under #2327 and CI.

Supported watcher behavior is limited to local filesystems where the native watcher can produce
bounded events. For unavailable native watch, null filenames, event overflow, root replacement,
unsafe paths, and replay gaps, Keiko exposes degraded or `rescanRequired` status and requires a
snapshot refresh. Keiko does not claim strong real-time guarantees for NFS, SMB, container bind
mounts, or case-folding edge cases beyond the degraded contract tested here.

Workspace snippets intentionally support only Keiko's bounded, server-owned TextMate subset. VS Code
global snippets, extension snippets, regex transforms, clipboard variables, shell snippets, and
marketplace snippets remain unsupported and must not be advertised as parity.

AI activation is consent and discoverability only. It never widens Model Gateway, egress, sandbox,
review-first patch apply, budget, or delivery authority.
