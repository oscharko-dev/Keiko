## Current Read-First Reuse Map

The implementation must extend existing capabilities instead of creating parallel systems:

- Contracts: add browser-safe wire types to `@oscharko-dev/keiko-contracts`.
- Local Knowledge: reuse capsules, capsule sets, retrieval runner diagnostics, lexical/vector
  index metadata, and Knowledge Pod summary redaction.
- Retrieval semantics: preserve ADR-0036 rank-fusion semantics and do not present direct
  cross-space raw vector score comparisons.
- Evidence/security: reuse existing redaction and evidence-safe validation patterns; activity is
  a safe projection, not a new evidence store.
- Server BFF: expose activity only through existing grounded-answer orchestration boundaries.
- UI: render within existing grounded answer and Local Knowledge surfaces using component-scoped
  styling; do not edit global CSS.
