# Epic #3384 — acceptance-to-test/evidence map

Deliverable of #3390 ("Publish acceptance-to-test/evidence mapping"). This document maps every
acceptance criterion of every child issue (#3385, #3386, #3387, #3388, #3389, #3390, #3397, #3398,
#3399, #3400, #3401) and every epic-level Definition-of-Done item to concrete evidence on the
current integration tree: the test file/title that exercises it, the production file that
implements it, and a closed status.

## Method and scope

- Criteria are taken verbatim (shortened for the table) from each issue's own "Acceptance
  Criteria" section, read together with that issue's "Contract corrections" comment, which is
  authoritative where the two disagree.
- Every test file cited was opened and its test title confirmed present by direct inspection; every
  production file:line cited was opened and read. No citation in this document was taken on faith
  from an earlier audit pass without being independently re-opened here.
- The working tree is under active, concurrent multi-agent edit with a periodic checkpoint commit.
  This map was produced against checkpoint `02cb5f4b` (2026-09-05T12:09 local); a later checkpoint
  can move specific line numbers without changing the file or the behaviour described. Treat line
  numbers as approximate pointers, not pins.
- No command in this pass ran the full test suite, a build, or a repository-wide lint/typecheck —
  only targeted `grep`/file reads, consistent with this task's read-only, no-build scope. Where a
  status below says a suite "passes", that reflects a prior verified run recorded in this epic's own
  audit trail (two independent review passes over this exact worktree earlier the same day), cross-
  checked here by re-reading the cited test and production code, not by re-running vitest in this
  pass.

### Status vocabulary

- **implemented** — the criterion's behaviour exists in production code, is exercised by a named
  test, and no known gap remains open against it.
- **partial** — the criterion is substantially implemented but a concrete, named gap remains (dead
  code, an unwired production seam, a missing catalog entry, missing captured evidence, etc.).
- **blocked-external** — the criterion cannot be closed from this repository alone; the closed
  reason is one of: `#2198` (fresh signed/notarized platform receipts), `#2951/#3421` (sidecar
  filesystem/egress containment qualification), `#2952` (reference-container performance
  calibration), `operator-run keiko-issue-audit` (the independent audit tool runs outside this
  repository), or `human merge checkpoint` (the owner's explicit review/merge action).
