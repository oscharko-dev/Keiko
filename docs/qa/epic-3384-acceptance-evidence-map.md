### Status vocabulary

- **implemented** — the criterion's behaviour exists in production code, is exercised by a named
  test, and no known gap remains open against it.
- **partial** — the criterion is substantially implemented but a concrete, named gap remains (dead
  code, an unwired production seam, a missing catalog entry, missing captured evidence, etc.).
- **verified-source / verified-composition** — the stated source or production-composition
  checks passed; this does not imply real-model, packaged-platform or final merge qualification.
- **qualification-pending / deferred-final-gates** — authorized verification remains to be run
  or retained against the final source. Live execution, reference-container measurements and the
  independent final audit are owned work, not missing operator permission.
- **deferred-postmerge** — the claim requires actual merge/reachability facts and cannot be
  emitted in advance.
- **blocked-external** — the stated platform qualification is unavailable within this task.
  Signing exclusions remain explicitly unqualified; required confinement proof is not waived.
