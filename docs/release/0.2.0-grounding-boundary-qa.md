# Keiko 0.2.0 Grounding Boundary QA

Date: 2026-06-15
Workspace: `/Users/oscharko-dev/.codex/worktrees/96ed/Keiko`
Scope: Epics #177 and #189 as functional context for repository grounding, local knowledge connectors, mixed grounding sources, retrieval quality, and the 16-source chat grounding release contract.

## Decision

Status: **PASS with measured scale observation**

The release-critical grounding paths pass static gates, unit/integration tests, installable smoke tests, and a synthetic mixed-format boundary run using the local `.env` and `keiko.config.json` metadata. The boundary run found and drove fixes for XLSX ingestion, `/var` to `/private/var` realpath handling, over-limit mixed source capping, and large-corpus exact-match recall.

Residual observation: retrieval over 62,490 vectors remains a brute-force scan. With hybrid lexical recall enabled, the synthetic corpus returns 8/8 expected top sources, with most query p95 values around 190-230 ms and one PDF query p95 around 540 ms. This is acceptable for 0.2.0 local desktop scale, but an ANN/FTS-backed index should be considered before materially larger capsules.
