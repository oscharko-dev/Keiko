# Third-party brand assets

## Jira

`jira.svg` is the unmodified `jira/SVG/Jira_icon.svg` from Atlassian's official
[Jira app logo archive](https://atlassian.design/assets/553497c77711/logos/jira_app.zip),
linked by the [Atlassian Design logos page](https://atlassian.design/foundations/logos/).
Retrieved on 2026-11-04.

- Archive SHA-256: `72efda1307f9bb8985471c93b3fdaa4e0b9d36144cbf33ef9acbea37c00ae73f`
- The official tile, geometry and blue (`#1868DB`) are preserved. The UI displays it
  at 15 × 15 pixels inside the shared 32 × 32 Knowledge Pod icon box, with `Jira`
  alternative text. The icon box, name typography and spacing match Knowledge Pods.
- The SVG contains only static vector elements and internal clip-path references.
  It is served locally; displaying it makes no request to Atlassian or a CDN.
