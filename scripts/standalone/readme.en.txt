Keiko
=====

This folder contains everything Keiko needs. Nothing is installed on your computer.


Start
-----

macOS:   double-click "Start Keiko.command"
Windows: double-click "Start Keiko.cmd"

A small window shows the start. When Keiko is ready, it opens in your browser.
The first start can take a minute.


Stop
----

macOS:   double-click "Stop Keiko.command"
Windows: double-click "Stop Keiko.cmd"

Closing the browser tab does not stop Keiko. Start Keiko again to open it again.


Good to know
------------

- Keep this folder on your own computer, for example in Documents. Do not start
  it from a network drive.
- Do not open, move or change anything inside the folder "system".
- Your chats and settings are kept in the folder ".keiko-standalone" in your user folder,
  not in this folder. They stay when you replace this folder with a newer one.
- A new version arrives as a new folder. Stop Keiko, delete the old folder and
  use the new one.


If Keiko does not start
-----------------------

- macOS shows "cannot be opened" or "cannot be verified", or Windows shows
  "Windows protected your PC": this copy still carries the mark of an internet
  download. Take the folder from the place your administrator named, or ask
  your administrator.
- The window says that Keiko could not start: read the message in the window,
  then start Keiko again. If it stays, tell your administrator what it says.
- Keiko asks for a gateway address and an API token: your administrator has
  them.
